# Prompt Library Index

Use these prompts with the relevant agent specification in `agents/development/`.

| Prompt | Use |
|---|---|
| `MASTER_BUILD_PROMPT.md` | Begin the project and establish the orchestrated build process. |
| `ORCHESTRATOR_PROMPT.md` | Plan the next phase and coordinate scoped work. |
| `ARCHITECT_PROMPT.md` | Design/refine boundaries before implementation. |
| `IMPLEMENTATION_PROMPT.md` | Implement one assigned milestone. |
| `ROUTER_REVIEW_PROMPT.md` | Audit route decisions and policy tests. |
| `EVALUATION_PROMPT.md` | Build/review dataset, scorer, and benchmark integrity. |
| `QA_RELIABILITY_PROMPT.md` | Test failure paths and release readiness. |
| `OBSERVABILITY_SECURITY_PROMPT.md` | Audit trace, cost, logging, privacy, and spend controls. |

Do not send all prompts at once as an unconstrained swarm. Use the sequence in `agents/README.md` and the roadmap.
