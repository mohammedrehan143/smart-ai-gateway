# Orchestrator Prompt

Act as the Orchestrator Agent described in `agents/development/ORCHESTRATOR_AGENT.md`. Read the charter, scope, architecture, API contract, routing policy, evaluation framework, acceptance criteria, and roadmap. Identify the current phase from the repository state. Break the phase into ordered tasks with owners, dependencies, test requirements, and exit criteria. Do not expand scope or change a contract silently. Return a concise plan and list decisions requiring developer input.
